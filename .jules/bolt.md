## 2026-01-29 - Single Pass Variance Calculation in Manifold Heap
**Learning:** The `ChebyshevGuard::calculate` function in `ManifoldHeap` was performing two passes over the memory blocks to calculate mean and variance separately. This is a common pattern when following the mathematical definition directly. However, in a performance-critical "metabolism" loop (GC), this doubles the memory access overhead.
**Action:** Always check for opportunities to compute statistics (mean, variance) in a single pass using Welford's algorithm or accumulated sums, especially when iterating over large data structures.
## 2024-05-24 - [Avoid Intermediate Tensors for Scalar Reductions]
**Learning:** Scalar-returning functions in `ml::linalg` (like `mse`, `euclidean_distance`, and `rbf_kernel`) that use tensor operations like `a.sub(b)` and `.mul()` were generating intermediate `Tensor` instances. These operations trigger heap allocations for the underlying vector, shape, and stride data, combined with RC overhead, causing significant performance bottlenecks on CPU compared to a single-pass loop.
**Action:** When computing scalar reductions (like distance metrics or mean loss) between tensors, borrow the underlying data buffers using `.data.borrow()` and compute the reduction manually in a single loop to avoid all intermediate heap allocations.
