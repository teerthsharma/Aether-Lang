## 2026-08-07 - Functional Iterator Chains for Tensor Reductions
**Learning:** In Aether's linear algebra library, manual index-based loops over tensor data (`for i in 0..n`) prevent LLVM from eliding bounds checks effectively and hinder auto-vectorization. High-level tensor operations like `a.sub(b)` are also detrimental as they trigger costly intermediate heap allocations.
**Action:** When computing scalar reductions (like `mse`, `mae`, or distance metrics), always assert shape equality first, then perform a single-pass iteration directly over the underlying borrowed data arrays using functional iterator chains (e.g., `.iter().zip().map().sum()`).
