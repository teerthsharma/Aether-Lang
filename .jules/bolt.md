## 2026-08-17 - [Tensor Iteration Avoids Heap Allocations]
**Learning:** In Aether-core's ML linalg operations, high-level tensor operations like `a.sub(b)` and `.mul()` when computing scalar reductions and element-wise differences trigger costly intermediate heap allocations due to creating new `Tensor` metadata. Using single-pass iterators (`.iter().zip().map()`) directly over the borrowed data arrays and consuming the resulting vector with `Tensor::from_vec()` elides bounds checks and allows LLVM to auto-vectorize more effectively, avoiding redundant O(N) slice allocations.
**Action:** Replace manual index-based loops with iterator chains and `Tensor::from_vec()` in core machine learning hot loops.
