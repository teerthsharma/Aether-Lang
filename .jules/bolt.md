## 2026-01-29 - Single Pass Variance Calculation in Manifold Heap
**Learning:** The `ChebyshevGuard::calculate` function in `ManifoldHeap` was performing two passes over the memory blocks to calculate mean and variance separately. This is a common pattern when following the mathematical definition directly. However, in a performance-critical "metabolism" loop (GC), this doubles the memory access overhead.
**Action:** Always check for opportunities to compute statistics (mean, variance) in a single pass using Welford's algorithm or accumulated sums, especially when iterating over large data structures.
## 2026-02-09 - Avoid High-Level Tensor Allocations in Scalar Reductions
**Learning:** During calculations that result in a scalar value (e.g., loss functions like MSE, MAE or distances like Euclidean/Manhattan), using high-level tensor operators like `.sub()` or `.mul()` on dynamic `Tensor`s backed by heap allocations (`Rc<RefCell<Vec<f64>>>`) causes unnecessary and expensive intermediate heap allocations. Furthermore, relying on `.min()` for array length checks across tensors can mask shape mismatch errors.
**Action:** Always assert shape equality `assert_eq!(a.shape, b.shape)` and compute scalar reductions by directly iterating over the borrowed arrays (`a.data.borrow()`) in a single pass. This is crucial for operations in the hot path of the network such as loss function computation.
