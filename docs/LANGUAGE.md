# Language Reference

This compatibility page points to the current language documentation:

- [Syntax](language/syntax.md)
- [Execution Model](language/execution-model.md)
- [Module Contracts](language/modules.md)
- [Language Pipeline](concepts/language-pipeline.md)

The active language surface includes variables, assignment, arithmetic,
comparison, logical operators, lists, functions, `if`, `while`, `for`,
`seal until`, imports, manifolds, blocks, and topology module calls.

Parsed syntax and runtime behavior are separate claims. A feature should be
documented as active only when the interpreter or Titan VM path has evidence.
